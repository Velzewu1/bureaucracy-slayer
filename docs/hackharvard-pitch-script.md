# HackHarvard unified product pitch

## Three-minute version

### 0:00–0:25 — The problem

Say: “A browser agent can find a Cancel button. That does not mean policy allows the
user to press it. Bureaucracy Slayer turns one goal and one observed website into an
evidence-bound decision—and refuses to guess when verification is incomplete.”

Point to **Evidence-bound**, **Fail-closed**, and **Guidance only**.

### 0:25–0:50 — One action, explicit provenance

Point to the fixed goal, selected Northstar website, and the single **Analyze Website**
button. During an offline judging run, point to **Offline mock configured**.

Say: “The production action starts our bounded collector and two-stage extraction. For
this rehearsal the exact same client lifecycle is connected explicitly to a sanitized
deterministic mock, so it makes zero paid model calls and cannot be mistaken for fresh
Sonnet output.”

### 0:50–1:20 — Verified delivery

Click **Analyze Website**. Point out collection, source selection, extraction, and
validation phases. After completion, show **Deterministic offline mock**.

Say: “A model may propose a procedure map. It cannot authorize it. The browser
recomputes hashes, Semantic Audit, evidence validation, evaluation, and planning.”

### 1:20–1:55 — Refusal is a result

Show **Human review required**, the semantic qualifier finding, excluded cancellation,
and an exact citation.

Say: “The saved Sonnet result found relevant procedures, but its permission omitted a
mandatory qualifier. Exact text provenance still passes; semantic audit rejects the
overbroad permit. Bureaucracy Slayer withholds the action instead of silently fixing or
dropping the rule.”

### 1:55–2:30 — Usable personalization and local replanning

Open **Guided**, then **All facts**, and change an applicable fact such as Standard to
Instant.

Say: “These controls come only from the verified canonical model. Guided and All Facts
share one state. Every answer reruns the real three-valued evaluator and dependency
planner locally—no Claude call, no browser collection, and no mutation of the actual
state during counterfactual analysis.”

Point to the trace, counterfactual explanation, citations, and any route comparison.
Emphasize that user facts cannot clear an evidence-review gate.

### 2:30–3:00 — Close

Say: “The differentiator is separation of powers. A model proposes structure; observed
IDs, hashes, source bindings, semantic audit, three-valued evaluation, and deterministic
planning decide whether it is usable. Bureaucracy Slayer helps an agent know not only
where it can click, but when it should stop.”

## 60-second version

Say: “Bureaucracy Slayer takes one goal and one website. Analyze Website collects and
extracts policy evidence, but the model never authorizes an action. Deterministic hashes,
Semantic Audit, evidence validation, evaluation, and planning do that.”

Click **Analyze Website** in the probed offline-mock setup.

Say: “This lifecycle is a clearly labeled sanitized mock, so it makes no paid call. The
result requires review because a mandatory qualifier is missing. We preserve exact
citations and withhold the permission. Once canonical facts arrive, Guided and All Facts
become interactive; changing a fact replans locally without another model or browser
run. The product’s core behavior is evidence-linked guidance—and safe refusal.”

## Optional ready-route fallback

If judges ask to see a fully authorized route, restart the UI with the explicit
`verified_fixture` execution policy described in the runbook. Disclose the transition:

Say: “This is our hand-checked deterministic fixture, not fresh extraction. It uses the
same validator, evaluator, planner, Decision Intelligence, and UI. Scheduled + Standard
permits the evidenced cancellation route; changing Standard to Instant activates the
prohibition while the observed button remains present.”

## Presenter truth rules

- Normal product startup is genuine live analysis.
- Offline mock is explicit, deterministic, sanitized, and makes zero Anthropic calls.
- Recorded replay is genuine prior Sonnet output and remains review-required.
- Verified fixture is hand-checked replay and is the ready-cancellation demonstration.
- Exact citation matching proves captured provenance, not legal correctness.
- Bureaucracy Slayer gives guidance only and never submits a financial action.
